# Kids TV

A free, home-screen web app that lets a toddler watch only a hand-picked list of YouTube channels (up to 20). No search, no home feed, no YouTube suggestions.

- `index.html`, `config.js`, icons, manifest: the app (served by GitHub Pages)
- `backend/Code.gs`: Google Apps Script backend (shared channel list in a Google Sheet, parent PIN, YouTube Data API calls)
- `docs/SETUP.md`: one-time setup
- `docs/PARENT-GUIDE.md`: guide for parents
